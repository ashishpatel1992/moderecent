# Changelog

## 1.1.0 — 2026-10-19

- Added an optional **From / To** date range filter (in the user's timezone). When set it overrides the "last N days" preset, and it is kept through every action and confirmation.

## 1.0.0 — 2026-10-19

- Initial release.
- ACP page (Extensions → Moderate Recent) listing the latest topics and posts for a chosen period.
- Per-row actions: delete topic, delete post, delete all posts by the author, delete the author and their posts.
- Checkbox selection with a bulk-action dropdown and confirmation summary.
- Protection for the current user, guests, bots, founders, administrators and global moderators.
- Moderator/administrator log entries for every deletion.
- English and French translations.
